# 🏷️ GitHub Badges Customizer

Create custom GitHub badges with live preview, templates, and easy integration for your repositories.

## ✨ Features

- **Custom Badges**: Create personalized shields.io badges
- **Live Preview**: See your badge in real-time as you design
- **Template Library**: Pre-built badge collections for common use cases
- **Color Customization**: Choose from preset colors or use custom hex codes
- **Style Options**: Flat, plastic, flat-square, for-the-badge, and social styles
- **Logo Integration**: Add Simple Icons logos to your badges
- **Copy & Export**: Get markdown, HTML, or direct URLs
- **Batch Creation**: Create multiple related badges at once

## 🚀 Usage

1. **Choose Template**: Start with a pre-built template or create custom
2. **Customize Content**: Set label, message, and colors
3. **Select Style**: Pick from various badge styles
4. **Add Logo**: Include relevant technology logos
5. **Copy Code**: Get markdown, HTML, or URL for your badge

## 🎨 Badge Styles

- **Flat**: Clean, minimal design (default)
- **Plastic**: Glossy, 3D appearance
- **Flat Square**: Sharp corners, modern look
- **For The Badge**: Large, bold style
- **Social**: GitHub-style social badges

## 🏷️ Pre-built Templates

- **Build Status**: CI/CD pipeline badges
- **Version Info**: Release and version badges
- **License**: Open source license badges
- **Social**: Stars, forks, contributors
- **Download Stats**: Package download counts
- **Code Quality**: Coverage, grade badges
- **Language**: Programming language badges

## 🌈 Color Options

- **Named Colors**: blue, green, red, orange, yellow, brightgreen, success, important, critical
- **Hex Colors**: Custom hex color codes (#FF6B6B)
- **Auto Colors**: Dynamic colors based on content

## 🔗 Integration

```markdown
<!-- Markdown -->
![Badge](https://img.shields.io/badge/label-message-color)

<!-- HTML -->
<img src="https://img.shields.io/badge/label-message-color" alt="Badge">

<!-- RST -->
.. image:: https://img.shields.io/badge/label-message-color
   :alt: Badge
```

## 💡 Pro Tips

- Use consistent colors across your project badges
- Keep labels concise and descriptive
- Leverage Simple Icons for technology logos
- Group related badges together in your README
- Update badges regularly to reflect current status
