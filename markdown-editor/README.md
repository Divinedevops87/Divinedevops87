# ✍️ Live Markdown Editor

Real-time markdown editor with syntax highlighting, live preview, and theme switching for comfortable editing.

## ✨ Features

- **Real-time Preview**: See formatted output as you type
- **Syntax Highlighting**: Color-coded markdown syntax
- **Split View**: Side-by-side editor and preview
- **Theme Options**: Multiple editor themes
- **Export Options**: Download as .md or .html
- **Full Screen**: Distraction-free editing mode
- **Auto-save**: Local storage backup
- **Responsive Design**: Works on all screen sizes

## 🚀 Usage

1. **Start Typing**: Enter markdown in the left panel
2. **See Preview**: Live preview appears on the right
3. **Choose Theme**: Select from various editor themes
4. **Export**: Download as markdown or HTML
5. **Full Screen**: Toggle full screen for focus

## 📝 Markdown Support

- **Headers**: # ## ### #### ##### ######
- **Emphasis**: *italic* **bold** ***bold italic***
- **Lists**: Ordered and unordered lists
- **Links**: [text](url) and [text][ref]
- **Images**: ![alt](url)
- **Code**: `inline` and ```code blocks```
- **Tables**: GitHub-flavored markdown tables
- **Strikethrough**: ~~crossed out~~
- **Horizontal Rules**: ---
- **Blockquotes**: > quoted text

## 🎨 Editor Themes

- **Default**: Clean and minimal
- **Dark**: Dark background for night coding
- **GitHub**: GitHub-style editor

- **Monokai**: Popular dark theme

## 💾 Auto-save Features

- **Local Storage**: Automatically saves to browser
- **Session Recovery**: Restore work after browser restart
- **Export Backup**: Download regular backups
- **Version History**: Keep track of changes

## 📱 Mobile Optimized

- **Touch Friendly**: Optimized for touch devices
- **Responsive Layout**: Adapts to screen size
- **Gesture Support**: Swipe between editor/preview
- **Virtual Keyboard**: Works with mobile keyboards
