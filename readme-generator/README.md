# 📝 README Generator

A professional README.md generator with templates, badges, and live preview functionality.

## ✨ Features

- **Professional Templates**: Multiple pre-built templates for different project types
- **Badge Integration**: Automatically generate relevant badges for your project
- **Live Preview**: See your README in real-time as you edit
- **Export Options**: Download as .md file or copy to clipboard
- **Dark/Light Theme**: Switch between themes for comfortable editing
- **Mobile Responsive**: Works perfectly on all device sizes

## 🚀 Usage

1. **Choose a Template**: Select from various professional templates
2. **Fill in Details**: Enter your project information in the form
3. **Customize Badges**: Add relevant badges for your project
4. **Preview & Export**: See live preview and download when ready

## 🛠️ Technology Stack

- **Frontend**: HTML5, CSS3, Vanilla JavaScript
- **Styling**: Custom CSS with CSS Grid and Flexbox
- **Icons**: Unicode Emojis and SVG icons
- **Export**: File API for downloads

## 📱 Responsive Design

The README generator is fully responsive and works on:
- 📱 Mobile devices (320px+)
- 📱 Tablets (768px+) 
- 💻 Desktops (1024px+)
- 🖥️ Large screens (1440px+)

## 🎨 Theme Support

- 🌞 Light theme (default)
- 🌙 Dark theme
- Auto-detection of system preference
- Persistent theme selection
