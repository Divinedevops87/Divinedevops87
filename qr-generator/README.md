# 📲 QR Code Generator

Create customizable QR codes for repositories, contact information, and any text or URL with styling options.

## ✨ Features

- **Multiple Input Types**: URLs, text, contact info, WiFi credentials
- **Customizable Design**: Size, colors, error correction levels
- **Logo Integration**: Add custom logos to QR codes (coming soon)
- **Multiple Formats**: PNG, SVG download options
- **Batch Generation**: Create multiple QR codes at once
- **Real-time Preview**: See your QR code as you type
- **Mobile Optimized**: Perfect scanning from mobile devices

## 🚀 Usage

1. **Enter Content**: URL, text, or select a preset template
2. **Customize Appearance**: Size, colors, error correction
3. **Preview**: Real-time QR code generation
4. **Download**: Save as PNG or SVG format
5. **Test**: Scan with your mobile device to verify

## 📱 QR Code Types

- **Website URLs**: Direct links to your projects
- **GitHub Repos**: Quick access to repositories
- **Contact Info**: vCard format for easy contact sharing
- **WiFi Credentials**: Share network access securely
- **Plain Text**: Any text content
- **Email**: Mailto links with subject and body
- **Phone Numbers**: Direct dial links
- **SMS**: Pre-filled text messages

## 🎨 Customization Options

- **Size**: 128x128 to 1024x1024 pixels
- **Colors**: Foreground and background colors
- **Error Correction**: Low, Medium, Quartile, High
- **Margin**: Adjust white space around code
- **Format**: PNG (raster) or SVG (vector)

## 💡 Pro Tips

- Use high error correction for outdoor displays
- Ensure good contrast between foreground/background
- Test QR codes at intended display size
- Include a short URL for better error correction
- Add contact info QR codes to business cards

## 📱 Mobile Testing

Always test your QR codes with actual mobile devices:
- iPhone Camera app
- Android Camera app
- Dedicated QR scanner apps
- Social media app scanners
