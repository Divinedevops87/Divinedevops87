# Dynamic README Generator Templates

This directory contains modular templates for different sections of the README.

## Available Templates

- `header.md` - Animated header with typing effects
- `about.md` - Personal information section
- `skills.md` - Animated skill bars
- `stats.md` - GitHub statistics and metrics
- `projects.md` - Featured projects showcase
- `footer.md` - Footer with dynamic content and animations

## Usage

Templates are automatically loaded by the main generation script and can be customized independently.
