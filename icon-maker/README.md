# 🎨 App Icon Maker

Generate beautiful app icons in multiple formats (SVG, PNG, ICO) with various styles and customization options.

## ✨ Features

- **Multiple Formats**: Generate SVG, PNG, and ICO formats
- **Custom Styles**: Choose from various design styles and themes
- **Text & Emoji Support**: Use text, emojis, or combine both
- **Color Customization**: Full color picker with gradient support
- **Size Options**: Multiple preset sizes and custom dimensions
- **Real-time Preview**: See your icon as you design it
- **Batch Export**: Download all sizes at once
- **Dark/Light Theme**: Switch between themes for comfortable editing

## 🚀 Usage

1. **Choose Style**: Select from circle, rounded square, or custom shapes
2. **Add Content**: Enter text, emoji, or upload an image
3. **Customize Colors**: Pick background and text colors
4. **Set Dimensions**: Choose from presets or set custom size
5. **Download**: Export in your preferred format(s)

## 🛠️ Supported Formats

- **SVG**: Scalable vector graphics (recommended)
- **PNG**: High-quality raster images
- **ICO**: Windows icon format
- **Multiple Sizes**: 16x16, 32x32, 64x64, 128x128, 256x256, 512x512

## 🎨 Design Options

- ⬜ Square icons
- 🎨 Custom gradients
- 🌈 Color palettes
- ✨ Shadow effects
